# Práticas de ADS - 1º Período

Este repositório foi criado para organizar e centralizar todas as atividades práticas, laboratórios e projetos desenvolvidos durante o **1º período** do curso de **Análise e Desenvolvimento de Sistemas (ADS)**.

O foco principal deste semestre foi construir uma base sólida em lógica de programação e dar os primeiros passos no desenvolvimento web frontend.

---

## Tecnologias Utilizadas

O aprendizado foi dividido em dois pilares principais:

### Programação e Lógica
* **Python**: Utilizado para o aprendizado de lógica de programação, estruturas condicionais, laços de repetição, funções e manipulação de estruturas de dados básicas (listas, tuplas e dicionários).

### Desenvolvimento Web (Frontend)
* **HTML5**: Estruturação de páginas web e semântica.
* **CSS3**: Estilização, layouts responsivos, Flexbox e Grid.
* **JavaScript**: Adição de comportamento dinâmico, manipulação do DOM e eventos.

---

## Organização do Repositório

As pastas estão divididas por linguagens. Abaixo está o sumário de conteúdos:

### Orientações sobre os exercícios práticos
* **`Orientacao/..`**: Arquivos PDF com as orientações passadas pela universidade.

### Estilos
* **`CSS/Estilos/..`**: Arquivos CSS com os estilos respectivos a cada arquivo HTML.

### Práticas em Python
* **`python/carro alugado.py/`**: Exercícios iniciais proposto para calcular o valor de um aluguel de carro.
* **`python/comandos de entrada e saida/`**: Série de fórmulas e funções iniciais do Python.

### Práticas Web (HTML, CSS & JavaScript)
* **`html/tabelas.html/`**: Arquivo HTML com foco no uso de tabelas.
* **`html/tabelas_imagens.html/`**: Arquivo HTML com foco no uso de tabelas, inserção de imagens e uso de hyperlinks.
* **`html/formulario.html/`**: Arquivo HTML com foco no uso de tags iniciais do HTML5, com foco em 'radio', 'input', 'checkbox' e 'textarea'.
* **`html/mini-site/`**: Arquivo HTML com foco no uso de tags de texto e listas/sublistas.
* **`css/marcadores.css/`**: Arquivo CSS utilizando formatação de texto e listas.
* **`css/paginainicial.css/`**: Arquivo CSS com o primeiro uso do mesmo de facto.
* **`css/pseudoclasses.css/`**: Arquivo CSS abordando uso de imagens com hyperlinks e propriedade _hover_.
* **`css/quadrados.css/`**: Arquivo CSS sobre dispor elementos em áreas diferentes da janela.

## Como Executar as Práticas

### Rodando os scripts Python
1. Certifique-se de ter o [Python](https://www.python.org/) instalado na sua máquina.
2. Navegue até a pasta do script desejado:
   ```bash
   cd python/nome_da_pasta
   ```
3. Execute o arquivo:
   ```bash
   python nome_do_arquivo.py
   ```

### Visualizando os projetos Web
1. Navegue até a pasta do projeto web:
   ```bash
   cd html/nome_da_pasta
   ```
2. Abra o arquivo `nome_do_arquivo.html` diretamente em qualquer navegador de sua preferência, ou utilize a extensão **Live Server** no [VS Code](https://code.visualstudio.com/).
